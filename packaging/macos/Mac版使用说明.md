# AI投标系统 · Mac 版使用说明

适用于 Apple 芯片（M1/M2/M3/M4…）的 Mac，macOS 11 及以上。不需要安装 Python 或任何其他软件。

## 第一次打开（只需要做一次）

这个应用没有经过苹果公证，第一次打开时 macOS 会拦一下，按下面任选一种方式放行：

**方式一（图形界面）**
1. 双击「AI投标系统」，弹出「无法打开」的提示，点「完成」；
2. 打开「系统设置 → 隐私与安全性」，往下翻到「安全性」，会看到「已阻止使用 AI投标系统」，点「仍要打开」，输入开机密码；
3. 再双击一次「AI投标系统」，点「打开」。

**方式二（终端一行命令）**
打开「终端」，粘贴下面这行后回车（应用放在「下载」文件夹时；放在别处请改成实际路径）：

```
xattr -cr ~/Downloads/AI投标系统.app
```

之后直接双击即可。

建议把「AI投标系统」拖进「应用程序」文件夹，以后从启动台打开。

## 日常使用

- **双击图标**：自动在后台启动、自动登录、打开浏览器。第一次会问是否载入演示数据。
- **关闭浏览器**：后台不会停止，定时采集照常进行；想再打开，再双击图标点「打开系统」。
- **停止运行**：再双击图标点「停止运行」，或在网页右上角账号菜单里点「退出程序」。
- **补采**：电脑睡眠或程序关闭期间错过了定时采集，下次启动时会自动补采一次。

## 数据在哪里

所有数据只保存在这台电脑：

```
~/Library/Application Support/AI投标系统/
  data/      数据库、上传的文件、导出的标书、公告快照（备份这个文件夹即可）
  logs/      运行日志（出问题时把 server.log 发给技术支持）
  runtime/   运行环境（可以删除，下次启动会自动重建）
```

在应用运行时再次双击图标，点「打开数据文件夹」可以直接打开。

## 升级

用新版本的「AI投标系统」覆盖旧版本即可，数据会保留。

## 常见问题

- **双击没反应**：看看屏幕右上角是否有通知；第一次启动需要准备运行环境，约 10~30 秒。
- **提示启动失败**：按提示打开日志 `logs/server.log`，把最后几十行发给技术支持。
- **端口被占用**：应用会自动从 8600 往后找空闲端口，无需处理。
- **多人一起用**：本机版只有这台电脑能访问。团队协作请部署网站版（见项目 README「快速开始 → Docker」）。
